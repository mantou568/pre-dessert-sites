# 贡献指南

本分支用于维护 Media Saber 社区公开站点配置，并为后续 upstream PR 做准备。

## 可以贡献

- 补充公开站点配置和站点清单。
- 检查配置文件名与顶层 `id` 是否一致。
- 记录公开配置中登录结构、用户基础信息、搜索和签到请求的结构状态。
- 修复经过核实的公开配置问题。

## 禁止提交的内容

不得提交账号信息、Cookie、Token、API Key、密码、登录状态或其他私人配置数据。不要连接个人 Media Saber 数据库，也不要从私人实例导出数据。

提交前检查变更文件和差异，确保只包含公开站点配置或文档。若意外发现认证资料，应从提交内容中移除，并避免在文档、日志或提交说明中复述。

## 修改已有官方配置

不要仅凭推测修改已有官方配置。先新增或更新 `CHANGE_PROPOSAL.md`，写明：

1. 当前问题及其公开配置位置。
2. 建议修改内容。
3. 需要完成的验证。

验证和审查完成后，再单独提交配置修改，并在可能时通过 upstream PR 分享修复。

## 新增站点

- 将公开配置放在 `site_config/sites/`，遵循仓库现有命名约定。
- 在 `docs/MY_SITES.md` 和 `docs/SITE_STATUS.md` 中补充对应记录。
- 只填写站点公开配置所需的结构，不加入任何个人账号或认证值。
